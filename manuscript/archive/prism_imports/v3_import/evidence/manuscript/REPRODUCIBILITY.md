# Reproducibility record

## Environment and installation

The canonical dependency declaration is `pyproject.toml`; the frozen resolver
state is `uv.lock`. Preferred setup:

```bash
uv sync --frozen --extra dev
```

This checkout lacks `uv`; Phase 9.8 verification therefore uses the existing
`.venv` (Python 3.14.6) and records that deviation.

## Pipelines

Historical pipelines are documented for replay into **new** output directories.
Never point them at frozen `outputs/phase95_v0.9.5/`,
`outputs/phase96_v0.9.6/` or `outputs/phase97_v0.9.7/`.

```bash
.venv/bin/python -m soil_simulator.phase95.pipeline
.venv/bin/python -m soil_simulator.phase96.pipeline
```

artifacts, copies/indexes them and creates presentation exports/manifests.
