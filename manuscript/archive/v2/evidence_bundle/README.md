# Manuscript evidence bundle

This directory is a verified evidence index for bounded drafting in Prism. It
is not a manuscript and contains no finished paper sections. Start with
`PRISM_HANDOFF.md`, then use numerical claims only through
`RESULTS_EVIDENCE.md`, the canonical CSV tables, and their cited source
artifacts.

The bundle supports methodological/software evaluation and a bounded portfolio
case study. It does not support an agricultural prediction or intervention-
recommendation paper. Sensitivity evidence is explicitly non-converged.

The independent Phase 9.6 clean-slate and Phase 9.7 focused re-audit
deliverables are archived byte-for-byte and validated against the supplied
export manifest. The focused re-audit supports bounded methodological,
software/simulator or portfolio drafting; see `docs/audits/README.md`.
